MLang sigils — every operation is one character.

Two rules the effect column assumes, and the two things most often got
wrong by someone writing MLang for the first time:

  Operands come first. Everything an operation needs is on the stack
  before its glyph runs, so the glyph is written last: «5»⍎ parses,
  s « »⊆ splits, L [⍎]∵ maps, L i @ indexes. Writing ⊆« », ∵[⍎] or f@0
  faults as `stack underflow`, with the caret on the glyph written early.

  Names are one glyph. ≔ ⇒ ↥ ↧ ⇂ ⇈ ⇟ each swallow exactly one glyph as
  their argument (⇉ takes two), so ⇒pos binds the local p and then
  references o and s. Store with ⇒q and read it back as a bare q — ↧q is
  not a local at all, it receives from channel q and blocks. `mlang check`
  names both of these before the program runs.

──────────────────────────────────────────────────────────────────────────────
∂      dup           a → a a             duplicate top of stack
⇅      swap          a b → b a           swap top two values
⌫      drop          a →                 discard top of stack
⊚      over          a b → a b a         copy second value to top
⥀      rot           a b c → b c a       rotate third value to top
≢      depth         → n                 push current stack depth
+      add           a b → a+b           add numbers
-      sub           a b → a−b           subtract (binary only; write negatives as ¯5)
×      mul           a b → a×b           multiply numbers
÷      div           a b → a÷b           divide; int÷int stays int when exact, else float; ÷0 glitches
%      mod           a b → a%b           modulo; %0 glitches
^      pow           a b → aᵇ            exponentiation
√      sqrt          a → √a              square root (float); negative glitches
⌊      floor         a → ⌊a⌋             floor to int
⌈      ceil          a → ⌈a⌉             ceiling to int
±      neg           a → −a              negate a number
=      eq            a b → 1|0           equal (any types; deep for lists)
≠      ne            a b → 1|0           not equal
<      lt            a b → 1|0           less than (numbers or strings)
≤      le            a b → 1|0           less or equal
>      gt            a b → 1|0           greater than
≥      ge            a b → 1|0           greater or equal
∧      and           a b → 1|0           logical and
∨      or            a b → 1|0           logical or
¬      not           a → 1|0             logical not
⊻      xor           a b → 1|0           logical exclusive or
!      apply         [q] ! → …           run a quotation
?      if            c t e ? → …         if c truthy take t else e; a quotation runs, a value is pushed
⟳      while         [c] [b] ⟳ → …       run [c]; while it leaves truthy, run [b] and repeat
⍣      repeat        n [b] ⍣ → …         run [b] n times
∵      map           L [f] ∵ → L′        run [f] on each item, collect results into a list
∀      each          L [f] ∀ → …         run [f] on each item for its effects
⌿      filter        L [f] ⌿ → L′        keep items for which [f] leaves truthy
⍀      fold          L a [f] ⍀ → a′      fold: for each item run [f] as a x → a′
⍸      range         n ⍸ → ⟨0…n−1⟩       push the list 0,1,…,n−1
⍙      type          v ⍙ → v s           push the value's type name («int» «float» «str» «list» «quot» «∅») without consuming it
⌽      reverse       s ⌽ → s′            reverse a list or string
⍋      sort          s ⍋ → s′            sort ascending (stable): a string, or a list of all numbers / all strings
∈      contains      s v ∈ → 1|0         membership: substring of a string, or item of a list
⍷      find          s v ⍷ → i|¯1        index of first occurrence (substring or item), ¯1 if absent
#      length        s # → n             length of a string or list
⧺      concat        a b → ab            concatenate two strings or two lists
@      index         s i @ → v           item at 0-based index; out of bounds glitches
⊂      slice         s i j ⊂ → s′        slice [i, j) with clamping
⊆      split         s sep ⊆ → L         split string by sep; empty sep splits into characters
⊇      join          L sep ⊇ → s         join list items (stringified) with sep
⍕      to-str        v ⍕ → s             format any value as a string
⍎      parse-num     s ⍎ → n             parse a string as int/float; glitches if malformed
⌗      codepoint     c ⌗ → n             Unicode code point of a 1-char string
⍘      char          n ⍘ → c             1-char string from a Unicode code point
⚡      spawn         [q] ⚡ → id          spawn a new strand running [q]; inherits a copy of locals
⋈      join          id ⋈ →              block until strand id has finished
⍳      strand-id     → id                this strand's id (grid columns are 0,1,2,…; boot is ¯1)
≣      strand-count  → n                 number of main strands (the grid's width)
⌛      yield         →                   end this strand's scheduler slice early
⍥      try           [b] [h] ⍥ → …       run [b]; on glitch restore stack, push the glitch value, run [h]
↯      raise         v ↯ →               raise v as a glitch
⍞      println       v ⍞ →               print v and a newline
⊸      print         v ⊸ →               print v without a newline
⌨      readline      → s|∅               read a line from stdin, stripping the \n or \r\n ending (∅ at end of input; waits until all other strands are quiet, flushing pending ⊸ output first)
⌥      event         → e|∅              one raw input event: characters as themselves; «↵» Enter, «⌫ ⇥ ⎋»,
                                         the navigation block «↑ ↓ ← → ⇱ ⇲ ⇞ ⇟ ⌦ ⎀», control chords «^A»…«^Z»,
                                         a mouse press as ⟨«⌖» x y⟩; ∅ at end of input (lowest priority, like ⌨)
⍇      read-file     path ⍇ → s          read a whole file as a string; glitches if unreadable
⍈      write-file    s path ⍈ →          write string s to a file; glitches if unwritable
⍆      fetch         url ⍆ → s           HTTP(S) GET, body as a string; a hard 10s deadline — it delivers
                                         or glitches («⍆ cannot fetch …» / «⍆ … answered 404»), never hangs
⍄      send          ⟨url hs body⟩ ⍄ → s   HTTP(S) POST: hs is a list of ⟨name value⟩ headers, body is
                                         sent as-is, the response body comes back. A hard 60s deadline —
                                         it delivers or glitches, never hangs. ⍆ can only ask for what is
                                         already there; this says something first.
                                         Neither names an OS error — a run that did
                                         could not replay elsewhere; MLANG_HTTP_DEBUG
                                         puts the reason on stderr when you need it
⎆      accept        → ⟨id m path body⟩  the next HTTP request this program is serving, ∅ at end of input
                                         (lowest priority, like ⌨). Replay mode (default): ▷ frames on stdin;
                                         live mode (mlang serve / MLANG_PORT): a real listener
⍅      respond       ⟨id st type body⟩ ⍅ →   answer request id with status st; replay writes a ◁ frame,
                                         live writes the real HTTP response; unknown id glitches
⟐      source        → s                 the program this grid is currently running, as text
⟡      weave         s ⟡ → ⟨status rpt⟩   re-weave this grid into program s — the loom (§4.7) from the
                                         inside. 200 and the loom's report, or 409/422 and why. A text
                                         that does not weave changes nothing; each strand takes the new
                                         code at its own seam, so nothing blocks and nothing restarts
⍟      debug         →                   dump this strand's stack to stderr
⌂      args          → L                 the program's command-line arguments, a list of strings
⍜      termsize      → ⟨rows cols⟩       the terminal size (⟨24 80⟩ when there is no terminal)
⌚      clock         → ms                the wall clock in Unix milliseconds; the MLANG_CLOCK
                                         environment variable pins it for reproducible runs
⌹      readdir       path ⌹ → L          sorted directory listing; directory names end with /
⌸      canvas        w h title ⌸ →       open a w×h pixel canvas — a real window when the
                                         session has a display, else headless: ⌸ and each ⎙
                                         print one line (size/title, frame hash) so recorded
                                         runs stay byte-exact; MLANG_FRAMES=dir dumps PPMs
▦      rect          x y w h c ▦ →       fill a rectangle with color c (0xRRGGBB as an int)
⌶      text          v x y c ⌶ →         draw v (stringified) in color c from the baked 8×16
                                         font; ⏎ wraps to the next glyph row
⎙      present       →                   show the frame: blit to the window, or print the
                                         frame's hash when headless; ⌥ then reads the window's
                                         keys and mouse (⟨«⌖» x y⟩ in pixels) instead of stdin
≔X     define        v ≔X →              bind v (often a quotation) to global sigil X; rebinding glitches
⇒X     store         v ⇒X →              pop v into strand-local sigil X (rebindable)
↥X     send          v ↥X →              send v down channel X (never blocks; unbounded FIFO)
↧X     recv          ↧X → v              receive from channel X; blocks until a value arrives
⇂X     try-recv      ⇂X → v 1 | 0        non-blocking receive: value and 1, or just 0
⇈X     pour          L ⇈X →              send each item of a list/string down channel X, then the ∅ end-marker
⇟X     drain         ⇟X → L              collect from channel X until ∅ into a list (blocks as needed)
⇉XY    pump          [f] ⇉XY →           for each value from channel X run f (v → v′) and send to Y; forward ∅ and stop

literals:  123  ¯5  2.5  «string»  (⏎ = newline)  ⟨1 2 3⟩  [quotation]  ∅
layout:    ⇓ first line = rain form (columns are strands, read downward)
           ⇊ divider = boot section above, strands below
           ⋮ line prefix = continue previous strand (flat form)
           ※ comment to end of line (flat) / end of column (rain)
libraries: std sigils (π ∑ ⊃ ◧ ⍢ …) print with `mlang std`; the
           Construct — the UI library (Ⓛ Ⓑ Ⓥ Ⓦ ⌺ ▶ scripted, ⏵ live
           …) — with `mlang ui`; the Operator — the JSON library
           (⒥ parse, ⒮ serialize, ⒢ get, ⒫ dig) — with `mlang json`.
           Bundled libraries are woven in automatically when their
           sigils are referenced
